Multiverse Version ranges Omniflake GitHub

Boot any package nixpkgs ever shipped, in this tab. Pick a package and a version from 13 years of nixpkgs history; its closure is fetched from cache.nixos.org into a Linux guest running in WebAssembly and you get a shell with the package on PATH. Nothing runs on a server.

GUI programs open as windows on the page too.

Try: hello · ripgrep and jq · python 3.6.2 from 2017 · jujutsu · two eras of hello at once · python 3.10 with openssl 1.1 · a patched hello from another cache · benchmark the emulator · foot in a window · galculator · GL gears · solitaire · mousepad · mpv · wev · firefox · weston

    Each spec resolves on its own to the newest build that matches; the versions need not have coexisted in one nixpkgs. Booted side by side, each package brings its own dependencies, so a mix that never coexisted still runs.

    Guest

    Guest memory

    For the aarch64 guest. It takes memory only as programs use it, so a large guest costs nothing until something fills it; a browser that cannot set the size aside gets a smaller one. A link can ask for a size with mem=.

    Guest CPUs

    For the aarch64 guest, each CPU in a worker of its own. The default leaves half your machine's threads to the browser; you can give it up to all of them, at most 16, the guest kernel's limit. A link can ask for a count with cpus=.

    Downloads

    For the aarch64 guest; the x86_64 guest always downloads everything first. A link can ask with fetch=all or fetch=lazy.

    GUI programs

    On the aarch64 guest a Wayland program opens a window under the terminal: type its name at the shell. Programs that only speak X11 do not start, since the guest has no X server. A GL program also downloads the site's GL driver, Mesa with only the virgl driver, which draws through your browser's WebGL2; to use another, select a mesa with the program and the page adds none of its own. Tested in Chrome and Firefox.

    Binary caches

    Extra binary caches, one per line, as a URL and its public key. They go into this page's link with the selection, so a store path from your cachix and the key that vouches for it are one link to send. Signatures are checked against these keys as the closure is walked; a cache has to allow cross-origin reads for a page to fetch from it at all.

    or start over in a fresh VM

    Packages added to a running VM appear in the shell straight away; the most recently added one wins when two provide the same command. A command the shell has already run once is remembered at its old path until hash -r.
