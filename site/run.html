VM How it works

The same store path the VM boots, run with no CPU emulator at all: its x86-64 machine code is translated to WebAssembly here in the tab, block by block, and its system calls are answered by JavaScript. An experiment, on a curated subset of what the VM can run; translate.md has the design and the limits.

?pkg=python3&exec=python3, ?pkg=ruby&exec=ruby&arg=-e&arg=puts+1, or ?path=/nix/store/…&exec=jq&arg=--version
